# 01_intro

## What is C#?

C# (pronounced "C-sharp") is a modern, object-oriented programming language developed by Microsoft in 2000. It is part of the .NET platform and is widely used for building Windows applications, web services, games (with Unity), and enterprise software.

## Getting Started with C#

You can write C# on Windows, macOS, or Linux. The easiest way is to use Visual Studio Code (VS Code) and the .NET SDK.

**Install .NET SDK:**

- [Download .NET](https://dotnet.microsoft.com/download)

**For Windows & Mac:**

1. Install VS Code
2. Install the C# extension (by Microsoft)
3. Install the .NET SDK

**Create a new console project:**

```bash
dotnet new console -o MyFirstApp
cd MyFirstApp
dotnet run
```

## Where is C# Used?

- Desktop apps (Windows)
- Web APIs and services
- Game development (Unity)
- Cloud and enterprise software

## What is .NET?

.NET is a free, open-source developer platform for building many kinds of applications. C# is the main language for .NET.

## C# vs Other Languages

### Python vs C#

- Both are high-level and object-oriented.
- Python is dynamically typed; C# is statically typed.
- Python is interpreted; C# is compiled.

**Python:**

```python
print("Hello, world!")
```

**C#:**

```c#
Console.WriteLine("Hello, world!");
```

### JavaScript/TypeScript vs C#

- JavaScript/TypeScript run in browsers; C# runs on .NET.
- TypeScript and C# are both statically typed, but C# is compiled.
- Syntax is similar for basic constructs.

**JavaScript:**

```js
console.log('Hello, world!');
```

**TypeScript:**

```ts
console.log('Hello, world!');
```

**C#:**

```c#
Console.WriteLine("Hello, world!");
```
