# Software Engineering Course - C# Examples

This solution has been reorganized to separate different C# learning topics into individual projects.

## Project Structure

Each example topic from the original `hello_world/Examples/` folder has been converted into its own standalone project:

### Core Projects

1. **BasicConcepts** - Basic I/O, math operations, type casting, operators
2. **Functions** - Function fundamentals, parameters, ref/out keywords
3. **StringExamples** - String manipulation, formatting, interpolation
4. **LoopExamples** - For loops, while loops, do-while loops
5. **CollectionExamples** - Arrays, Lists, Dictionaries
6. **OOP** - Object-oriented programming with structs and classes

### Additional Projects

7. **Debugging** - Debugging techniques and examples
8. **Exceptions** - Exception handling patterns
9. **Exercises** - Programming exercises and challenges
10. **Files** - File I/O operations
11. **FormattingExamples** - Advanced string formatting
12. **Generics** - Generic types and methods
13. **Linq** - Language Integrated Query examples
14. **Records** - C# record types
15. **Vehicle** - Vehicle class examples

### Original Project

16. **hello_world** - The original project containing all examples

## How to Run

### Run Individual Projects

```bash
# Navigate to any project directory and run
cd BasicConcepts
dotnet run

# Or run from solution root
dotnet run --project BasicConcepts
```

### Build All Projects

```bash
# From the solution root
dotnet build
```

### Run in Visual Studio

Open `Software_Engineering_course.sln` in Visual Studio. Each project can be set as the startup project and run independently.

## Project Features

- Each project is a standalone console application
- Interactive menus where applicable (BasicConcepts, LoopExamples, CollectionExamples)
- Clear separation of concerns by topic
- All projects target .NET 9.0
- Consistent naming conventions
