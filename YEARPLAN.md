# 52-Week Software Development Bootcamp Plan (With Certification Prep)

## Goal

Deliver a realistic 1-year bootcamp that produces job-ready junior developers and includes:

- PCEP preparation and exam support in exactly 2 weeks
- Azure certification preparation and exam support in exactly 2 weeks

## Planning Assumptions

- Total length: 52 weeks
- Full-time schedule: 5 training days per week
- Exam target certifications:
  - PCEP (Python Certified Entry-Level Programmer)
  - Microsoft Azure Fundamentals (AZ-900)

## 52-Week Timeline

### Weeks 1-2: Foundations and Developer Setup (2 weeks)

- Computer basics, OS, file systems, terminal, VS Code, workflow
- Project: Developer Setup Project

### Weeks 3-8: Python, Computational Thinking, SQL Basics (6 weeks)

- Python fundamentals, control flow, functions
- Core data structures and algorithm thinking
- SQL SELECT and filtering basics
- Project: Python CLI Data Tool

### Weeks 9-10: PCEP Preparation and Exam (2 weeks)

- Week 9: PCEP exam domain review + daily drills + mock exam
- Week 10: Weak-area remediation + final mock + exam window

### Weeks 11-14: Web Fundamentals and Team Workflow (4 weeks)

- HTML, CSS, responsive design, accessibility
- Git/GitHub, pull requests, code review
- Agile basics and collaboration practices
- Project: Team Website Project

### Weeks 15-22: JavaScript and Browser Engineering (8 weeks)

- JavaScript fundamentals and advanced concepts
- Async programming, fetch, JSON, DOM
- Debugging, linting, refactoring
- Project: Interactive Web App

### Weeks 23-26: API and Three-Tier Architecture (4 weeks)

- HTTP, REST API design, client-server model
- Python backend + JavaScript frontend integration
- SQL persistence
- Project: Mini Full-Stack System

### Weeks 27-29: C# Essentials (Compressed) (3 weeks)

- C# syntax, OOP, collections, generics
- Project: C# Console Application

### Weeks 30-31: Architecture and Design Patterns (2 weeks)

- SOLID principles and practical patterns
- Refactoring exercises integrated with existing code

### Weeks 32-35: ASP.NET and Data Architecture (4 weeks)

- ASP.NET controllers and routing
- SQL deeper topics (joins, indexing, performance)
- MongoDB fundamentals (document model, CRUD)
- Project: Full-Stack Backend System

### Weeks 36-40: React and Next.js (5 weeks)

- React components, state, hooks
- Component design and frontend architecture
- Next.js routing and rendering concepts
- Project: React Dashboard

### Weeks 41-43: TypeScript and Quality (3 weeks)

- Types, interfaces, generics, validation
- Testing basics and quality checks for frontend/backend
- Project: TypeScript Refactor

### Weeks 44-45: Production and Cloud Foundations (2 weeks)

- Docker, Dockerfile, docker-compose
- Azure basics, deployment concepts, CI/CD overview
- Project: Production Deployment

### Weeks 46-47: Azure Certification Preparation and Exam (2 weeks)

- Week 46: AZ-900 topic map review + lab-based practice + mock exam
- Week 47: Weak-area remediation + final mock + exam window

### Weeks 48-49: Applied AI for Developers (2 weeks)

- Practical AI APIs, prompt workflows, safe integration patterns
- Build one small AI feature into an existing app

### Weeks 50-52: Final Capstone (3 weeks)

- Team project delivery with production-ready standards
- Required scope:
  - React/Next.js frontend
  - ASP.NET backend
  - SQL or MongoDB
  - Dockerized deployment
  - Azure hosting
  - One AI-powered feature
  - Tests and documentation

## Must-Have vs Optional Content

### Must-Have (core job readiness)

- Python, JavaScript, TypeScript
- Git/GitHub team workflow
- API development and database integration
- Testing and code quality fundamentals
- Docker and Azure deployment basics
- PCEP prep (2 weeks) and AZ-900 prep (2 weeks)
- Capstone project

### Optional/Stretch (if extra time is available)

- Deeper C#/.NET specialization
- Advanced MongoDB optimization
- Extended AI agents and MCP implementation depth
- Additional cloud services beyond AZ-900 scope

## Portfolio Outcomes by Week 52

- Developer Setup Project
- Python CLI Data Tool
- Team Website Project
- Interactive JavaScript Web App
- Mini Full-Stack System
- C# Console Application (compressed track)
- Full-Stack Backend System (ASP.NET)
- React Dashboard
- TypeScript Refactor Project
- Production Deployment Project
- AI-Enhanced Feature Project
- Final Full-Stack Capstone
